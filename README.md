# MetaForge
MetaForge PDF designed and implemented as a comprehensive PDF metadata management solution

MetaForge PDF designed and implemented as a comprehensive PDF metadata management solution featuring:
Core Functionality:
Dual-engine scanner for Document Info Dictionary and XMP metadata
Hidden data detection with privacy risk scoring (0-100)
Visual metadata tree with JSON/XML views
Smart CRUD forms and raw XMP editor
Batch operations and metadata templates
Selective wipe, flattening, and one-click nuke functionality
Advanced Security:
Cryptographic redaction and metadata password protection
Digital signatures with SHA-256 hashing
Malware and script scanning
Immutable audit trail logging
Comprehensive permissions configuration
Performance & Optimization:
Tiered compression suite (Low/Medium/High)
Document properties viewer
Fast web view status checking
Enterprise-scale batch processing
Intelligent Features:
AI metadata generation with local LLM integration
Cross-format sync with CSV/JSON export/import
Git-style metadata version control
Cloud integration capabilities
UI/UX Excellence:
Neumorphic design system with 4 themes
Live PDF preview with split-screen editing
Interactive SVG risk visualization
Drag-and-drop workflows
Full accessibility compliance
Technical Architecture:
Rust core engine for security and performance
Electron/Tauri desktop framework
Local AI processing with privacy preservation
SQLite for local storage and audit logs
